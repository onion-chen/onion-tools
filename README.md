# 洋葱工具箱

一个用来收藏和导航常用站点的工具站。把日常使用的工具集中到一个页面，点击卡片即可跳转到对应网站。

## 功能简介

- **工具墙**：以卡片形式展示所有已注册工具，包含图标、名称、描述、分类和域名。
- **注册工具**：通过「添加工具」填写名称、链接、分类、图标和描述，提交后立即出现在工具墙中。
- **编辑工具**：随时修改已注册工具的名称、链接、分类等信息。
- **删除工具**：删除前会二次确认，避免误操作。
- **搜索**：按名称、描述、分类或链接关键词实时筛选。
- **分类筛选**：按开发工具、AI 工具、设计资源、效率办公等分类浏览，也支持自定义分类。
- **快捷跳转**：点击工具卡片，在新标签页打开对应站点。
- **链接校验**：仅支持 http/https 链接，未填写协议时自动补全为 `https://`；相同链接不会重复注册。

## 使用方式

1. 打开首页浏览已收录的工具。
2. 点击右上角「添加工具」注册新工具。
3. 鼠标悬停卡片可编辑或删除，点击卡片即可跳转到对应站点。
